# v3.2：3D 版击杀特效移植到 2D 版 + 项目清理 + 加密发布

> 需求：把 3D 版本的击杀特效实装到 2D 版本，加密导出发布包，然后清理项目文件夹、删除不必要文件。

## 1. 3D 版的击杀特效是什么

在 `lan-shooter-3d/public/` 里，击杀反馈由四层组成：

| 层 | 实现 | 3D 版表现 |
|---|---|---|
| 击杀确认卡 | `ui.js::drawKillConfirm` | 540×92 切角面板、渐变底、`KILL CONFIRMED` 标题、`ELIMINATED` 大字、击杀徽章（双环+叉）、扫描高光、底部进度扫条、`+积分 / COMBAT SCORE`、HVT 金色变体 |
| 准心冲击环 | `killImpactT` + `ui.js::drawKillImpact` | 击杀瞬间从准心扩散的红色圆环 + 4 条斜向短线，430ms 淡出 |
| 血雾 | `spawnBlood(x,y,kill?22:8,channelColor)` | 击杀时 22 个化学通道色粒子爆开（普通命中 8 个） |
| 震屏 | `shake += ev.kill ? 7 : 2` | 击杀 7、命中 2、死亡 10 |

## 2. 2D 版缺什么、补了什么

2D 版原来只有"简化击杀卡"（400×62 圆角面板 + 骷髅）和血雾/震屏，**没有准心冲击环**，击杀卡也不是 ELIMINATED 样式。本次移植：

1. **新增 `killImpactT` + `drawKillImpact()`**：准心红色冲击环 + 4 条斜线，430ms 淡出；在 `drawHUD` 里紧跟击杀确认卡之后绘制。
2. **击杀确认卡换成 3D 版 ELIMINATED 样式**：切角面板、渐变、双环徽章、`KILL CONFIRMED // 击杀确认`、`ELIMINATED`、`你淘汰了 X`、`[武器 · 死因]`、`+分数 / COMBAT SCORE`、扫描高光、底部扫条；HVT 击杀走金色变体（`HVT BONUS`）。
3. **自适应纵向位置**：2D 版顶部还有"随机事件条"（y≈112）和"Boss 血条"（y≈142~196），ELIMINATED 卡（高 92）会压住它们——所以按状态自动下移：无事件 88、有事件 150、有 Boss 206。
4. **手机端同步**：`mobile.js` 的紧凑 HUD 也画同一套准心冲击环（缩小半径），击杀确认继续用手机版卡片。
5. 血雾/震屏 2D 版本来就有（击杀 22 粒、震屏 7），参数与 3D 版一致，未重复实现。

## 6. 已知限制

1. 3D 版的"击杀镜头/慢动作"类效果不存在（3D 版也没有），所以没有移植。
2. ELIMINATED 卡在 1366×768 下宽 540；若在极小窗口（如 800×600 分屏）会显得偏大，可调 `ui.js::drawKillConfirm` 的 `w`。
3. 2D 版与 3D 版的击杀卡配色一致（红 #ff315d），但 3D 版有透视投影的粒子，2D 用同一套 2D 粒子替代。
