# v3.1：可滚动列表 · 面板光标 · 随机事件系统 · Boss 战（超级 AI）

> 需求：①各种列表人多时排不到最后（要可滚动）②鼠标移到面板上时光标看不见 ③随机事件系统（独立、可扩展：全员喷子/全员刀/神速力…）④训练一个超级 AI 当 Boss（厚血、0 帧拉枪、放道具、可配特殊道具），能一打十，参展者按贡献给奖励 ⑤完成后加密打包。

## 1. 列表统一可滚动

| 列表 | 原来 | 现在 |
|---|---|---|
| 战绩榜（Tab） | 只显示前 14 行，人多了后面的永远看不到 | 显示 14 行窗口 + **滚轮滚动**，右侧滚动条 + 底部"共 N 人 · 滚轮滚动（第 x-y 行）" |
| 管理面板"人类玩家" | 最多 4 人，多的被截断 | 4 行窗口 + **滚轮滚动**，标题右侧显示"滚轮滚动 5-8 / 12" |
| 手机端战绩榜 | 固定 10 行 | **上下拖动滚动**，轻点关闭（拖动不关闭） |

实现：`scrollY.board / scrollY.admin` 两个偏移状态；绘制时只画窗口内的行（名次仍显示真实排名）；`boardScrollMax()/adminScrollMax()` 供滚轮 clamp。滚轮在面板打开时**只滚列表、不再切枪**（面板关闭后恢复切枪）。

## 2. 面板上的鼠标可见

原因：`style.css` 里 `#cv { cursor: none; }`（游戏内用自绘准星），面板也是画在同一张 canvas 上，所以系统光标一直是隐藏的。

修法：每帧/每次 mousemove 调 `updateCursor()`——
- 面板打开（战绩榜/实验手册/管理面板/新手教程/聊天输入）→ `cursor: default`；
- 鼠标悬停在管理面板按钮上 → `cursor: pointer`；
- 其它时候 → `cursor: none`（保留游戏内隐藏光标的观感）。

## 3. 随机事件系统（独立模块、可扩展）

新文件 `game/events.py`，与 `server.py` 解耦：事件只通过 `Game` 暴露的少量接口作用（`set_all_weapons / set_all_buff / clear_buffs / spawn_boss / despawn_boss / announce`）。

**加一个新事件 = 写一次注册**（不用改 server.py）：
```python
def _start(game, now):
    game.set_all_buff("speed", 1.8)

def _end(game, now):
    game.clear_buffs()

register_event("speed_demo", "神速力·演示", "所有人移速 ×1.8", 20.0, 1.0,
               on_start=_start, on_end=_end)
```

**内置 7 个事件**：喷淋器狂欢（全员 H₂O₂）、搅拌棒大乱斗（全员近战）、高氯酸狙击战、神速力（×1.7）、无限弹药、过载（伤害 ×1.5）、**Boss 战**。

调度：默认 45 秒后首个事件，此后间隔 70–110 秒随机；同一时刻只跑一个；最近两轮不重复；事件出错不会拖垮主循环（try/except）。
**开关**：环境变量 `RP_EVENTS=0` 关闭；主机面板 `B` → 「EVENTS // 随机事件」有「随机事件 / Boss 战 / 关闭事件」三个按钮；也可发 `{"t":"admin","act":"event","id":"boss|random|off|on|<事件id>"}`。

客户端：顶部事件条（名字 + 倒计时，最后 5 秒变红）、全屏播报横幅、Boss 战大血条与伤害贡献榜、结算面板。

## 4. Boss 战：超级 AI（规则型，不是新训练的模型）

**如实说明**：没有重新训练神经网络（机房/笔记本没有 GPU 训练预算，也不该为了"看起来强"而假称训练过）。Boss = **规则/状态机型超级 AI + 对局内强化参数**，用的是现有模拟器与化学系统，可解释、可调参：

| 参数（`game/events.py` 的 `BOSS_CFG`，可改） | 值 |
|---|---|
| 额外护盾 | **1400**（先扣护盾，护盾破了才进入 pH/缓冲伤害） |
| 伤害倍率 | ×1.6 |
| 开火间隔倍率 | ×0.75（更快） |
| 0 帧拉枪 | `aim_instant=True`：无反应延迟、无转向速度限制、无瞄准误差 |
| 道具连发 | 每 9 秒在目标脚下放烟、每 16 秒开 AOE、每 12 秒用指示剂标记 |
| 补给 | 弹匣空了瞬间补满（不断节奏） |
| 走位 | 远则压上、近则拉开、中距离横向绕（撞墙自动改向） |

**一打十实测**（同一进程模拟：1 Boss + 10 个普通 AI 挑战者，20 秒）：

| 指标 | 结果 |
|---|---|
| Boss 击杀 | **15 人**（挑战者总阵亡 15） |
| Boss 阵亡 | **0** |
| Boss 护盾 | 1400 → **260**（挑战者能打掉 81%，双向对抗成立） |
| 单帧耗时 | 平均 **0.19ms**、p95 0.29ms（1 Boss + 10 bot 同场仍远低于 16.7ms 预算） |

→ 结论：能同时压制 10 人；十个人集火约 25–30 秒可破盾，配合真人枪法会更快。若觉得太强/太弱，改 `BOSS_CFG` 的 `shield / dmg_mul / abilities` 即可，不用改代码逻辑。

**贡献奖励**：对 Boss 造成的伤害（含护盾阶段）按玩家累计；Boss 被击杀时按 `伤害/8` 发放积分，全屏播报「伤害贡献奖励：A(60)、B(37)…」，HUD 结算面板列出前 5 名（伤害 + 奖励分）。

## 6. 调整（同日反馈）

1. **Boss 战改为合作模式**：Boss 登场时把**所有玩家与机器人并入同一阵营**（记录原阵营），战后自动恢复——Boss 战期间玩家之间无友伤、可专心合力打 Boss；中途加入的玩家也会被并入。`despawn_boss()` 按备份恢复阵营（若当时是阵亡状态则按原阵营出生点复活）。红蓝比分不会因击杀 Boss 而加分。
2. **随机事件只保留一个提示**：原来"事件播报"同时触发了中间大横幅（`banner`）和事件面板（标题+说明），面板/横幅在 UH 0.24~0.32 区域重叠，小面板挡住了大横幅下方的说明。现在事件与 Boss 结算**只走事件面板**（标题 + 说明 + 倒计时），不再叠加横幅；地图切换/HVT 等其它横幅不受影响。

验证：`tests/events_boss_check.py` 扩到 **39/39**（同阵营、无友伤、中途加入并入、战后恢复原阵营）；真浏览器 E2E **17/17**（新增"只有一个提示：announce=true 且 banner 为空"）。

## 7. 已知限制

1. Boss 是规则型超级 AI，不是重新训练的权重；`LAN_AI_BOTS=1` 时普通机器人仍走原训练策略，Boss 两者都不走（独立状态机）。
2. 事件会作用到所有在线玩家（含教程局以外的机器人）；**教程小局内已禁用事件**（保持安静学习环境）。
3. 事件只跑在主对局：新开服/重开一局后事件计时重置；Boss 战被击杀或超时（90 秒）结束。
4. 手机端只做了精简版 HUD（事件名 + Boss 护盾条）；滚动是拖动；主机事件按钮只在 PC 管理面板。
